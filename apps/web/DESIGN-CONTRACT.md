# 우강테크 웹 설계 계약서 (v4 — 2026-09-02)

> 이 문서는 홈페이지를 손대는 모든 작업자(사람·에이전트)가 지켜야 하는 **강제 규격**이다.
> 근거 문서: `D:\전광판\teams\blog\research\web-benchmark-2026.md` (Apple/Toss/Linear/Stripe 실측 스펙)
> 목표: 국내 사이니지 업체 평균 대비 3배. Apple·Toss와 나란히 놓아도 밀리지 않을 것.

---

## 0. 절대 규칙 (어기면 반려)

1. **임의 값 금지.** `text-[42px]`, `py-[88px]`, `duration-[420ms]`, `rounded-[18px]` 같은 즉흥 수치를 새로 적지 않는다. 아래 토큰만 쓴다.
2. **이징은 4종.** `ease-entrance` / `ease-state` / `ease-scrub` / `ease-spring`. 새 cubic-bezier를 컴포넌트에 적지 않는다.
3. **이미지 경로 하드코딩 금지.** 반드시 `@/lib/imageAssets` 의 `IMAGES` 를 통해 참조한다.
4. **모션 부품은 `@/components/motion` 에서 가져온다.** `motion.div` 에 직접 transition을 적지 않는다. (부품에 없는 연출이 필요하면 그 파일에 부품을 추가하고 쓴다.)
5. **`prefers-reduced-motion` 경로가 없는 애니메이션은 금지.** motion 부품은 이미 처리돼 있다.
6. **애니메이션은 transform / opacity / filter 만.** `top`, `height`, `margin` 을 애니메이션하지 않는다.
7. **검증 불가능한 숫자·고객 로고·"만족도 99%" 금지.** 우리는 아직 첫 수주 전이다. 실적을 지어내지 않는다.
8. **끝내기 전 `npx tsc --noEmit` 통과.** (빌드는 총괄이 마지막에 한 번 돌린다.)

## 1. 타이포 토큰

유틸리티 클래스로만 쓴다 (`src/app/globals.css`).

| 클래스 | 용도 |
|---|---|
| `.wk-hero` | 홈 히어로 **한 곳만**. 자동으로 `max-width:14ch` 가 걸린다 |
| `.wk-display` | 다크 시네마틱 장면 제목 |
| `.wk-h1` | 페이지 H1 |
| `.wk-h2` | 섹션 제목 |
| `.wk-h3` | 카드·사례 제목 |
| `.wk-lead` | 리드 문장 (`max-width:38rem` 자동) |
| `.wk-body` | 본문 |
| `.wk-cap` | 캡션·각주. **핵심 정보를 여기 넣지 말 것** |
| `.wk-eyebrow` | 섹션 위 소제목 (uppercase, tracking 0.14em) |
| `.wk-metric` | 숫자 규격 (tabular-nums). 단위는 `<small>` 로 감싼다 |

- 제목의 힘은 크기가 아니라 **짧은 행 길이**에서 나온다. 한글 제목은 데스크톱 8~11음절에서 줄을 끊는다.
- 폰트는 Pretendard 한 가족. 굵기는 400/500/600/700만.

## 2. 레이아웃 토큰

| 클래스 | 용도 |
|---|---|
| `.wk-wrap` | 기본 컨테이너 (max 1200) |
| `.wk-wrap-wide` | 사진이 주인공인 섹션 (max 1440) |
| `.wk-wrap-read` | 긴 읽기 본문 (max 720) |
| `.wk-sec-sm` | 로고·인증·짧은 CTA (64/80/96) |
| `.wk-sec` | 일반 기능·규격 (80/96/128) |
| `.wk-sec-lg` | 사례·제품 장면 전환 (96/128/160) |
| `.wk-sec-xl` | 다크 시네마틱 시작/끝 (120/160/200) |

- 섹션 여백은 **한쪽에서만 소유**한다. 위아래 패딩이 겹쳐 320px 공백을 만들지 않는다.
- 섹션 제목→리드 20~28px, 리드→그리드 48~72px, 카드 간격 20~24px.
- 텍스트+이미지 2단은 5+7열 / 7+5열을 **한 번만** 뒤집는다. 매 섹션 지그재그는 템플릿 냄새다.

## 3. 색 · 표면

- 라이트 기본: 배경 `white` / `bg-wk-bgFaint` / `bg-wk-bg`, 텍스트 `text-wk-ink` → `text-wk-ink2` → `text-wk-ink3`.
- **흰 글자 CTA는 `bg-wk-cta`(#1B64DA)** 를 쓴다. `wk-blue`(#3182F6)는 흰 글자와 3.71:1 로 AA 미달이라 **버튼 배경 금지**, 장식·포커스링·`bg-wk-blueWeak` 위 아이콘에만 쓴다.
- 다크 섹션: `.wk-night` (#0B0B0F) + `.wk-night-card`. 텍스트 `text-wk-nightInk` / `text-wk-nightMuted`.
- 라이트↔다크 전환은 선이 아니라 `.wk-bridge-down` / `.wk-bridge-up` 그라디언트 다리로 잇는다.
- 사진 위 문구는 `.wk-scrim-l`(좌측 텍스트) 또는 `.wk-scrim-b`(하단 텍스트)를 깐다. 전면 검정 40% 오버레이 금지.
- 그림자는 `shadow-wk-1`(정보 행) / `shadow-wk-2`(사례·제품 카드) / `shadow-wk-3`(다크 위 부유 패널) 3단만.
- radius 포함관계: 카드 `rounded-card`(20) > 내부 미디어 `rounded-card-m`(16) > 버튼 `rounded-btn`(12). 대형 시네마틱 면만 `rounded-surface`(28).

## 4. 모션 부품 (`@/components/motion`)

| 부품 | 언제 쓰나 |
|---|---|
| `Reveal` | 일반 블록 등장. `y` 기본 22px |
| `RevealImage` | 사진 등장 (확대+블러 해제) |
| `Stagger` | 카드 목록. 자식이 70ms 간격으로 따라 들어온다 |
| `SplitText` | 제목을 어절 단위로 올린다. 페이지당 1~2회만 |
| `Parallax` | 배경 사진. 강도 0.12~0.2 |
| `StickyScene` | 화면 고정 + 스크롤 진행도로 장면 전환 (Apple형) |
| `Counter` | 숫자 증가. **근거 있는 수치에만** |
| `Marquee` | 흐르는 띠. 전광판 회사라 그 자체가 제품 데모 |
| `Spotlight` | 다크 카드 위 커서 광원. 라이트 배경 금지 |
| `Magnetic` | 주요 CTA 1~2개만 |
| `ScrollScale` | 큰 사진 한 장을 화면 폭까지 밀어 올릴 때 |

**모션 예산** — 한 페이지에 `StickyScene` 1개, `SplitText` 2개, `Magnetic` 2개를 넘기지 않는다. 전부 넣으면 놀이공원이 된다.

## 5. 반드시 피할 것 (안티패턴)

1. 첫 화면 자동 슬라이더 4~6장 → 히어로 한 장 + 사용자가 여는 갤러리
2. "최고의 기술력, 최상의 품질" → `6,000 nit`, `IP65`, `KC 적합등록` 같은 검증 가능한 속성
3. 무지개 그라디언트·네온 남발 → 중립 90% / blue 8% / 상태색 2%
4. 모든 카드에 두꺼운 그림자 + 30px radius
5. 접속 즉시 팝업·채팅·전화 버튼 3개 → 첫 CTA 하나, 40% 스크롤 뒤 sticky 바
6. 제목마다 다른 폰트·900 굵기
7. 스크롤할 때 모든 요소가 아래에서 튀어나옴 → 주요 장면만 24~40px, 목록은 opacity 중심
8. 모든 문장 가운데 정렬 → 중앙 정렬은 히어로 2~3줄에만
9. 제품 메뉴를 모델명만으로 구성 → "실내 고해상도 P1.8–P2.5"처럼 환경·성과를 먼저
10. PDF 아이콘만 있고 크기·날짜 없음 → `규격서 · PDF · 2.4MB · 2026-08 개정`

## 6. 이미지

- `IMAGES` 레지스트리(`src/lib/imageAssets.ts`)에 60장이 **중복 없이** 배정돼 있다. 배정을 바꾸려면 레지스트리를 고치고 중복 검사를 통과시킨다.
- 히어로 이미지 1장만 `priority`, 나머지는 lazy. `sizes` 를 반드시 정확히 준다 (격자면 `(min-width:1024px) 33vw, (min-width:640px) 50vw, 100vw`).
- 생성 이미지의 매끈함이 거슬리는 큰 장면에는 `.wk-grain` 을 얹는다.
- `alt` 는 "장소 + 제품 + 상황". 장식용이면 `alt=""` + `aria-hidden`.

## 7. 접근성

- 본문 대비 5:1 이상을 내부 목표로 한다. `wk-ink4`(#8B95A1)는 흰 배경에서 3.04:1이라 18px 미만 설명문에 쓰지 않는다.
- 모든 인터랙티브 요소에 포커스 링(globals.css에 전역 지정됨). 제거하지 않는다.
- 색만으로 상태를 전달하지 않는다. 선택 탭 = 색 + 2px 밑줄 + 굵기.
- 200% 확대에서 내비게이션·CTA·규격표가 잘리지 않아야 한다.

## 8. 카피 톤

- 독자는 **관공서·학교 담당 공무원**이다. 결재 문서에 붙일 근거를 찾고 있다.
- 과장·영어 남발 금지. "혁신적 솔루션" 대신 "부서가 바뀌면 화면에서 고칩니다".
- 문장은 짧게. 한 문단 3줄 이내.
